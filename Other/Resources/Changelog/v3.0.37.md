# Release notes

## Changes

- added test
- updated dependency
- the colors of the frontend were reworked into a single source of truth with one palette per theme-mode (`src/styles/_theme-colors.scss`), applied everywhere through Angular-Material's Material-3 theme: light-mode now has a very light, cool-white background with deep navy text and accents, and dark-mode a dark, GitHub-like grey background with light, non-white grey text; to restyle the application the palettes are changed there instead of overwriting single color-tokens
- the visual-regression-baseline-images now follow the form `<theme-mode>-<name>` (for example `light-home-page.png`) with a dash as the only word-separator instead of the former underscore-prefix (`light_<name>`); the tests were pointed at the renamed baselines and the dark-theme baselines which were missing for four scenarios are now in place
