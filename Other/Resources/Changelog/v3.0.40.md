# Release notes

## Changes

- migrated vitest-configuration to the Vitest-4-options so that the single-fork-mode is applied again and the test-run does not fail anymore with "Worker exited unexpectedly"
- Updated generated skills and openspec-specifications (findings can have the state `accepted`, rows of the findings-table are sorted automatically)
- Fixed British spellings in source-comments and documentation (American English)
- Updated Swashbuckle.AspNetCore to 10.3.1 so that the OpenAPI-specification-generation works with the swagger-CLI 10.3.1 of the SCBuilder-image again
