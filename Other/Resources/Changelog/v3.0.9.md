# Release notes

## Changes

- Added video-retention-period
- the user-interface follows material 3 completely now. The colors come from a palette which is generated from two seed-colors ("ConSurvFrontend/src/styles/_theme-colors.scss"), and every color-token exists in a light and in a dark value, which the css-property "color-scheme" selects. There is therefore no second theme which would have to be kept in sync with the first one, and the few places which had a fixed color (the popup of a camera-preview, the area behind a video-stream) use the tokens of the theme now and are readable in both schemes
- the visual-regression-tests check the user-settings-page in the light and in the dark color-scheme. The dark scheme is not a variation of a few colors of the light one, so a regression which only occurs there - an element which keeps a bright background, for example - would stay unnoticed if only one of the two was checked
