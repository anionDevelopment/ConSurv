# ConSurv

## Findings

This section collects the findings of all code-reviews, security-checks, bug-searches and performance-analyses which are documented in the markdown-files of this repository.
The ids `CSV-01` to `CSV-37` are taken from the OWASP-Top-10-analysis in `ReadMe.md` (performed on 2026-10-02 against commit `09b95ef`).
The ids `CSV-MT-01` to `CSV-MT-04` were assigned for the list "Missing security-tests" of the same analysis, because that list has no ids.
The ids `CSV-38` to `CSV-44` were added from the openspec specification-audit performed on 2026-10-10; they were checked directly in the source-code on that date.
The state was checked directly in the source-code on 2026-10-08.
